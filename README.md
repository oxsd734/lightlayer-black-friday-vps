## 这两款云机分别适合谁

新加坡那台的瓶颈在带宽。10Mbps 换算下来约 1.25MB/s，跑一个日访几百的静态站、挂个探针、做 API 转发、单用户代理，都够。不限流量这条对长期跑小流量的任务很友好，不用担心月底被掐。但你要拿它做图床、放安装包、给几个人同时看视频，10Mbps 会明显卡，这时候多花 $1.45 上圣何塞更划算。

圣何塞给的是 1Gbps 端口配 1TB 月流量，摊到 30 天每天约 33GB。这个组合适合有突发需求的场景：白天没什么流量、晚上集中跑同步或备份，一小时的峰值能拉起来。1TB 用完之后怎么处理，活动页没写，如果你的用量贴着上限，下单前问一下比较稳。

两款都是 1 核 1G。1G 内存跑 Debian 加 Nginx 加一个轻量应用没问题，装宝塔再挂 WordPress 多插件就会紧张。要跑面板、跑 Docker 多容器，这两档都不是合适的选择，别为了省几美元硬上。

独立服务器是另一个量级的需求。香港那台 20 核 32G 配 1TB SSD，$84/月，适合要把整个业务压在一台机器上、或者需要独立 IPv4 做邮件和证书的场景。洛杉矶那台 $40/月给的是 E5-2660 加 1TB 机械盘，平台老是事实，机械盘的随机读写也别期待，它的价值在于 8 核 8G 独享加 1TB 存储便宜，做备份节点、跑批处理、存冷数据合适，做数据库不合适。

## 首期价和真实总成本差多少

促销页只写月价，读者最容易漏算的是"按月付满一年到底多少钱"。

新加坡 $3.5 × 12 = **$42/年**，原价算是 $84，一年省 $42。圣何塞 $4.95 × 12 = **$59.4/年**，原价 $118.8。洛杉矶独服一年 $480，香港独服一年 $1008。

真正拉开差距的是第二年。条款写的是续费同价，也就是第二年按同样的单价续，两年总成本分别是 $84 和 $118.8，不是很多年付机那种"首年 $10、次年 $40"的结构。这一点在便宜 VPS 里不算普遍，值得单独拎出来看。

如果你确定要长期用，年付比月付更省。条款明确季付、半年付、年付都能同享活动价，还能叠加长周期折扣，具体折到多少只有结账页会显示，活动页没给数字，我不替它猜。做法很简单：选好机房和配置，在计费周期里切到年付，看总价对比一下 12 倍月价，差额就是长周期折扣。
